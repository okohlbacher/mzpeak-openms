<objective>
Close the scalar half of RDR-10b: extend the mzPeak C++ reader so each spectrum
exposes its `spectrum_type` (MS:1000559), lowest/highest observed m/z,
`data_processing_ref`, and its per-spectrum `parameters` CV-param list — the
descriptive metadata a lossless mzPeak→MSExperiment map (Phase 2) feeds into an
`MzMLHandler::handleCVParam_`-style accession→setter dispatch.

This is pure standalone mzpeak-lib work on branch `writer_test`. NO OpenMS code,
NO libOpenMS dependency — Phase 1 is independently executable ahead of Phase 0.

Purpose: Phase 2's converter cannot map per-spectrum CV terms it cannot read.
Output: Extended `SpectrumMetadata`, extended `read_spectra_metadata`, and a new
`spectrum_metadata_test` suite (the Wave 0 test scaffold for the whole phase).
</objective>
