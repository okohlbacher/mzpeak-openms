<objective>
Implement the unblocked subset of RDR-10c: surface per-spectrum precursor data
from `small.mzpeak`'s 34 MS2 spectra — precursor isolation window, activation
(CID + collision energy), and selected ions (m/z + intensity) — plus the
populated scan-level `parameters` and `scan_windows`. Model precursor as a
`std::vector<PrecursorInfo>` so the DIA / multi-precursor case maps cleanly to
OpenMS `MSSpectrum`'s `vector<Precursor>` in Phase 2.

DEFER ion-mobility decode only: `ion_mobility_value`/`ion_mobility_type` are NULL
in every bundled fixture, so leave a clearly-marked stub + deferred note rather
than write an unvalidated IM path.

Scan-level `parameters` + `scan_windows` are deliberately IN scope for Phase 1
(not deferred): see 01-RESEARCH.md `## Open Questions (RESOLVED)` Q3 — they are
populated in small.mzpeak, are needed by Phase 2's OpenMS `InstrumentSettings`
(scan-window) mapping, and are mechanically identical to the precursor/CvParam
decode path already built in plans 01-01/01-02, so marginal cost is ~zero.

Pure standalone mzpeak-lib work on branch `writer_test`. NO OpenMS code.

Purpose: a lossless MS2→MSExperiment map needs precursor/isolation/activation.
Output: PrecursorInfo / SelectedIonInfo / scan-window structs, the join read
path, and value-tested assertions vs small.mzpeak.
</objective>
