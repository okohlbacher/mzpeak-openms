<!-- M2 (review): DETERMINISTIC value stringification for CvParam.value.
     std::to_string(double) is FORBIDDEN for the value union — it yields
     "35.000000" for 35.0, making string asserts fragile against the real fixture
     value (collision energy 35.0, displayed "35"). Canonical rule:
       format_double_canonical(double v): print v via std::ostringstream with
       std::setprecision(17) and defaultfloat, then strip trailing zeros and a
       trailing '.' (35.0 -> "35", 1.5 -> "1.5", 810.789428710938 -> "810.789428710938").
     Per-arm stringification:
       "string"  -> string as-is (LargeStringArray::GetString)
       "integer" -> std::to_string(int64)                (exact)
       "float"   -> format_double_canonical(double)       (NOT std::to_string)
       "boolean" -> "true" / "false"
     Tests asserting a numeric value MAY parse-and-numeric-compare instead; tests
     asserting the canonical string MUST expect the canonical form (35.0 -> "35"). -->
